# Zargol Personal Portfolio

A bilingual (English/Persian) personal landing page built with plain HTML, CSS and JavaScript for GitHub Pages.

## Publish on GitHub Pages
1. Create a new repository, for example `zargol-portfolio`.
2. Upload **the contents of this folder** to the root of the repository.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch** → `main` → `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Files
- `index.html` — main bilingual portfolio
- `style.css` — responsive design and animation
- `script.js` — language toggle, mobile menu and interactions
- `resume.html` — updated printable resume (Print → Save as PDF)
- `assets/zargol-profile.png` — profile photo from supplied resume

## Notes
The interest-section backgrounds are loaded from Unsplash URLs, so the live site needs an internet connection to display those images.
